Store domains

The store answers on several domains at once: the primary GitHub Pages address plus its hosting mirrors, each serving the identical catalog from the same build. Your visit is assigned one of them automatically, so no single host carries all the traffic, and the Open the store button above always opens yours.

If that domain ever stops responding, the project page on the maintainer's site lists every mirror alongside the support and donation channels. Bookmark it: it is the page that gets updated whenever a domain changes.

FAQ

Where can I download patched ReVanced, MorpheApp or ReVanced Advanced apps?
NullStore lists every current build with its version, architecture and applied patches, and links straight to the original release files on GitHub.
Is this safe to install?
Every build links to its source release; nothing is re-hosted or re-signed by this site. Check the applied-patch list on each build card and install only what you trust.
Do I need root?
Patched APKs need no root. The catalog also carries Magisk and KernelSU modules for rooted devices, marked as Module downloads.
Can I get automatic updates?
Yes, every build exposes an Obtainium one-click install, so your phone checks for new builds itself.
How often is the catalog refreshed?
Automatically, within hours of any upstream release. This page and the store are rebuilt on a daily schedule from the live catalog.
Where can I see the source code?
The NullForge builder that patches and publishes every build, the store website that renders this catalog, and this gateway page are all open source on GitHub.

NullStore is an independent catalog; it is not affiliated with Google, ReVanced, MorpheApp or the developers of the patched apps. All builds link to their original public releases.
